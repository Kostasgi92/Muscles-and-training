# Μυϊκός Χάρτης

Τρισδιάστατος, ρεαλιστικός χάρτης των μυών του ανθρώπινου σώματος για την προπόνηση:

- **Άσκηση → μύες.** Γράφεις μια άσκηση (ελληνικά, αγγλικά ή greeklish, π.χ. «καθίσματα», «lat pulldown», «kathismata»)
  και ανάβουν πάνω στο σώμα οι **κύριοι** (κόκκινο) και οι **βοηθητικοί** (κεχριμπαρί) μύες, μαζί με βήματα εκτέλεσης,
  συμβουλές και συχνά λάθη. Αν η άσκηση δεν υπάρχει στη βάση, η εφαρμογή ρωτά το Claude (όταν τρέχει ως artifact στο claude.ai).
- **Μυς → ασκήσεις.** Πατάς έναν μυ πάνω στο μοντέλο και βλέπεις τι κάνει, τα τμήματά του και ασκήσεις όπου είναι
  κύριος ή βοηθητικός, με οδηγίες. Το κουμπί «Περισσότερες ασκήσεις από το Claude» φέρνει νέες ιδέες.
- **Προγράμματα.** Στην ενότητα «Προγράμματα» φτιάχνεις, αλλάζεις και διαγράφεις δικά σου προγράμματα (λίστα ασκήσεων).
  Στο claude.ai αποθηκεύονται ιδιωτικά στον λογαριασμό σου (δυνατότητα `db`), αλλιώς στον browser.
- **Αξιολόγηση προγράμματος** (κουμπί «Αξιολόγηση» / «Review»). Διαλέγεις ποια από τα προγράμματά σου κάνεις μέσα στην
  εβδομάδα και πόσες φορές, ορίζεις σετ ανά άσκηση ή προσθέτεις έτοιμα πρότυπα (Push/Pull/Legs, Άνω/Κάτω, Full body).
  Η εφαρμογή τα ενώνει σε μία εβδομάδα και βαθμολογεί από 0 έως 10 κάθε μυ, κάθε μυϊκή ομάδα και όλο το πρόγραμμα, με
  στόχο τη μυϊκή ανάπτυξη:
  - όγκος με τον «κανόνα του 10» (≥10 σκληρά σετ την εβδομάδα ανά μυ, βέλτιστο 10–20· οι μικροί βοηθητικοί μύες ≥6),
    με κλασματική μέτρηση (κύριος μυς = 1 σετ, βοηθητικός = ½),
  - συχνότητα (κάθε μυς 2 φορές την εβδομάδα), κατανομή (έως ~10 σετ ανά μυ σε μία προπόνηση),
  - ισορροπία ώθησης/έλξης, τετρακέφαλων/οπίσθιων και άνω/κάτω σώματος.

  Το σώμα χρωματίζεται ανά μυ (πράσινο = άριστα … κόκκινο = ελλιπώς, γκρι = καθόλου, μωβ = υπερβολικός όγκος) και, αν το
  ζητήσεις, παίρνεις προτάσεις βελτίωσης με κουμπιά που προσθέτουν τις ασκήσεις στο πρόγραμμα, καθώς και γνώμη προπονητή
  από το Claude. Η λογική βρίσκεται στο `src/review.js`· οι ρυθμίσεις της αξιολόγησης (σετ, φορές την εβδομάδα, αν μετράει
  στην εβδομάδα) αποθηκεύονται στο πεδίο `plan` κάθε προγράμματος.
- **Δύο γλώσσες.** Αγγλικά (προεπιλογή) και ελληνικά, με το κουμπί EN / ΕΛ.
- **Στρώσεις.** Επιφανειακοί → μεσαίοι → εν τω βάθει μύες → σκελετός. Οι βαθιοί μύες που δουλεύουν σε μια άσκηση φαίνονται
  και ως «λάμψη» μέσα από τους επιφανειακούς.

## Το μοντέλο

- 172 ανατομικά τμήματα (μύες, κεφαλές μυών, τένοντες/απονευρώσεις, οστά, μάτια), ~472.000 τρίγωνα, ~2,5 MB συμπιεσμένα.
- Γεωμετρία από το [Z-Anatomy](https://www.z-anatomy.com/) (βασισμένο στο BodyParts3D), μέσω του πακέτου
  [`@authorod/svitylo-3d-anatomy-data`](https://www.npmjs.com/package/@authorod/svitylo-3d-anatomy-data).
- Ρεαλιστική απόδοση: υλικά PBR με υγρή γυαλάδα, ψημένη σκίαση (ambient occlusion) ξεχωριστά για κάθε στρώση,
  και διαδικαστική υφή ινών που συγκλίνει προς την πραγματική έκφυση/κατάφυση κάθε μυός.

## Δομή

```
src/
  index.html, styles.css   σελίδα και σχεδιασμός (φωτεινό/σκοτεινό θέμα)
  main.js                  αναζήτηση, καρτέλες, αξιολόγηση προγράμματος, σύνδεση με τη σκηνή
  review.js                κανόνες και βαθμολογία προγράμματος, προτάσεις βελτίωσης
  templates.js             έτοιμα πρότυπα προπονητή για την αξιολόγηση
  lang.js                  γλώσσα: __G (μετάφραση υπαρχόντων κειμένων) και T(en, el) για νέα κείμενα
  viewer.js                three.js σκηνή, shaders, στρώσεις, επιλογή με κλικ, κάμερα
  anatomy.js               φόρτωση/αποκωδικοποίηση του anatomy.txt
  search.js                αναζήτηση με ελληνικά/αγγλικά/greeklish και ορθογραφικά λάθη
  claude.js                ερωτήσεις στο Claude για άγνωστες ασκήσεις (δυνατότητα artifact "sample")
  data/muscles.js          μύες: ελληνικά/λατινικά ονόματα, λειτουργία, τμήματα
  data/exercises.js        ~95 ασκήσεις με κύριους/βοηθητικούς μύες και οδηγίες
  data/lang-apply.js       περνά τη γλώσσα στα δεδομένα πριν χτιστεί η αναζήτηση
  addons/i18n.js           αγγλικά: λεξικό κειμένων και μεταφράσεις μυών/ασκήσεων (φορτώνεται πριν από το app.js)
  addons/programs.js       ενότητα «Προγράμματα», αποθήκευση (db ή browser), γραμμή «Πίσω», window.__mxPrograms
  addons/motion.js         κινούμενη φιγούρα της άσκησης, σχεδιασμένη από το Claude
tools/
  anatomy-map.mjs          αντιστοίχιση δομών Z-Anatomy → μύες της εφαρμογής
  build-anatomy.mjs        παράγει το public/anatomy.bin (απλοποίηση, διόρθωση φοράς, ίνες, AO)
  ao-worker.mjs            ψήσιμο ambient occlusion (three-mesh-bvh)
  build-app.mjs            χτίζει το dist/ (index.html, app.js, anatomy.txt, addons)
  serve.mjs                τοπικός server για δοκιμές
dist/                      έτοιμο προς δημοσίευση (το μοντέλο ως base64 στο anatomy.txt) (claude.ai artifact ή οποιοσδήποτε static host)
```

## Χτίσιμο

```sh
npm install
npm run build:anatomy   # προαιρετικό: ξαναφτιάχνει το public/anatomy.bin (~2 λεπτά)
npm run build           # dist/index.html + dist/app.js + dist/anatomy.txt + addons
npm run serve           # http://localhost:8080
```
